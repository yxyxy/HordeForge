# Fix: Patch Application Failures & Pipeline Logic Issues

## Executive Summary

The core problem: **patches are invalid because the LLM generates them against incomplete/stale file context, and the patch application pipeline has no validation or recovery mechanisms**. This creates a cascade of failures that prevents reaching a successful PR.

## Root Cause Analysis

### 1. LLM Gets Insufficient File Context (PRIMARY CAUSE)
- `_load_candidate_file_snippets()` loads only **3 files**, truncated to **3000 chars each**
- RAG returns **symbol-level chunks** (individual functions/classes), not full file context
- Pipeline YAML has **no file_contents or file_tree** in step inputs
- LLM generates patches based on partial understanding → patches target wrong locations

### 2. Patch Application Has No Tolerance (SECONDARY CAUSE)
- `materialize_patch_operations()` uses **exact `str.replace(old, new, 1)`** — no fuzzy matching
- `_apply_update_block()` in patch_text mode also uses **exact string match**
- **No whitespace normalization**, no line-offset tolerance, no context-aware matching
- When `old_string` not found: operation **silently skipped** (added to notes, not errors)

### 3. Stale File Content in Fix Loop (TERTIARY CAUSE)
- `code_generator` reads files at start, but after first patch + test run, files changed
- Fix agent delegates to `EnhancedCodeGenerator` which re-reads from `Path.cwd()` — may not be workspace
- Multiple components apply patches independently with different implementations

### 4. Information Loss in Feedback Loop
- Test failures truncated to **5 entries**, fix agent further truncates to **3 highlights**
- `failure_signature` hash is fragile — changes with different error message ordering
- Deterministic fallback **overwrites source files with comments**

class PatchValidatorAgent(BaseAgent):
    """Validates patches before application."""
    
    def run(self, context: dict) -> dict:
        code_patch = context.get("code_patch", {})
        workspace = self._resolve_workspace(context)
        
        errors = []
        
        # 1. Validate all target files exist
        for file_info in code_patch.get("files", []):
            path = workspace / file_info["path"]
            if not path.exists() and file_info.get("change_type") == "modify":
                errors.append(f"Target file does not exist: {file_info['path']}")
        
        # 2. Validate operations can be applied
        for op in code_patch.get("operations", []):
            if op.get("type") == "edit":
                path = workspace / op["path"]
                if path.exists():
                    content = path.read_text()
                    if op["old_string"] not in content:
                        errors.append(f"old_string not found in {op['path']}")

        return {
            "status": "SUCCESS" if not errors else "FAILED",
